# SEO Analyst Skill

## Purpose

Analyze organic performance and convert data into prioritized actions.

## Inputs

Where available:
- Google Search Console
- Google Analytics
- rank data
- website crawl data
- conversion/enquiry data

## Analyze

- impressions
- clicks
- CTR
- average position/rank
- landing pages
- queries
- indexing changes
- content performance
- service-page performance
- conversion signals

## Output

What changed
Why it matters
What is working
What is underperforming
Likely causes
Recommended actions
Priority
Measurement plan

Never fabricate missing metrics.
