# Internal Linking Strategy

## Objective

Use internal links to connect related Zediant pages into coherent topic clusters and help users move toward relevant commercial pages.

## Link hierarchy

Prefer:

Homepage
→ Service / Pillar
→ Supporting Topic
→ Related Supporting Topic
→ Case Study / Proof
→ CTA

## Link rules

Links must be:
- contextually relevant
- useful to the reader
- descriptive
- natural
- not excessive

Avoid:
- sitewide keyword-heavy anchor repetition
- forced links
- unrelated cross-links
- exact-match anchor stuffing

## Recommendation format

For every recommendation record:

Source Page
Target Page
Suggested Anchor
Context / Reason
Topic Cluster
Priority
Approval Required

## New content requirement

Every new approved page should be checked for:
- incoming internal links
- outgoing internal links
- orphan risk
- parent/pillar relationship
