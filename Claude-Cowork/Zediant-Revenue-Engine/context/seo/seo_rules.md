# Zediant SEO Rules

## 1. Search intent before keywords

Never create a page merely because a keyword has search volume.

Determine:
- search intent
- buyer stage
- ICP relevance
- commercial relevance
- service relevance
- geographic relevance

## 2. One primary intent per page

A page should have one dominant search intent. Do not force unrelated terms onto the same page.

## 3. Existing page before new page

Before proposing a new URL:
1. Check whether an existing page already addresses the intent.
2. Check for cannibalization.
3. Prefer improving or consolidating existing pages when appropriate.

## 4. No keyword stuffing

Use natural language, related terminology, entities and semantic variations.

## 5. No generic AI content

Do not use filler introductions, repetitive conclusions, keyword-stuffed prose or generic agency claims.

## 6. Evidence-driven claims

Unsupported claims must be flagged.

Current approved wording must be respected. For example, the Revenue Engine policy requires "SOC 2 Type II aligned" unless current approved evidence explicitly confirms completed certification. Never upgrade "aligned" to "certified."

## 7. No invented proof

Do not invent:
- statistics
- customer outcomes
- case studies
- testimonials
- certifications
- delivery capabilities
- project details

## 8. Conversion

Commercial pages should have a clear, relevant CTA. Informational content should provide a natural path to the relevant Zediant capability without forcing a sales pitch.

## 9. Cannibalization

Do not create multiple pages targeting essentially the same search intent without a documented reason.

## 10. Geographic SEO

Country or city pages must contain genuinely useful market-specific information. Do not mass-produce doorway pages.

## 11. Technical changes require approval

Human approval is required before:
- URL changes
- redirects
- canonical changes
- index/noindex changes
- deleting pages
- major service-page rewrites
- new commercial pages
- publishing content

## 12. SEO does not own CRM

SEO may identify or recommend conversion opportunities. It must not independently write business-process fields to Zoho CRM.

## 13. Unknown means unknown

Use:
- CONFIRMED
- LIKELY
- UNKNOWN
- REQUIRES HUMAN VERIFICATION

Never convert inference into fact.
